# AgriNova AI Decision System

*Hyperlocal, AI-powered agricultural advisory dashboard.*

## 🚨 The Problem
Farmers often struggle with inefficient resource allocation because they lack access to real-time, hyperlocal environmental data, leading to suboptimal irrigation and crop management.

## 💡 The Solution
AgriNova AI acts as a digital farm consultant, integrating weather APIs and Generative AI (Gemini) to provide actionable, location-specific advice on irrigation, planting, and harvesting schedules.

## 🛠️ Tech Stack
- **Frontend:** [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Tailwind CSS](https://tailwindcss.com/)
- **AI Engine:** [Google Gemini API](https://ai.google.dev/)
- **Data Source:** [OpenWeatherMap API](https://openweathermap.org/)
- **Deployment:** [Vercel](https://vercel.com/)

## ✨ Key Features
- **Hyperlocal Advisories:** Generates custom agricultural advice based on real-time weather.
- **Decision Dashboard:** Interactive UI for easy tracking of farm health and tasks.
- **Scalable Architecture:** Built for rapid deployment in agricultural tech environments.
